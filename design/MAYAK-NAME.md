# Название приложения: Маяк

Пользователь выбрал название «Маяк». Новые мобильные макеты используют это название и знак маяка. Пользователь утвердил цветовой вариант: 01 / «Тихая ясность». Основной акцент #235BD6, фон #F4F7FB, поверхности #FFFFFF, текст #182538, вторичный текст #5A6A80, мягкий акцент #E7EFFF, границы #D9E1ED.

Существующие PDF «Нить» остаются архивом предыдущего этапа; данный мобильный пакет относится к «Маяку». Проверка товарного знака и доменов не проводилась.
