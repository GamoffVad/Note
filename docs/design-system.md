# Дизайн-система «Маяк» — «Острова идей» 1.0

Все экраны всех версий приложения (Windows, macOS, Linux, Android, iOS)
строятся из компонентов библиотеки `@mayak/islands` (`packages/islands`).
Источник дизайн-системы — пакет «Mayak Islands Design System» от владельца
продукта: описание [`packages/islands/DESIGN-SYSTEM.md`](../packages/islands/DESIGN-SYSTEM.md)
и токены [`packages/islands/tokens.json`](../packages/islands/tokens.json).

## Библиотека `@mayak/islands`

- **Токены.** `src/styles/islands-tokens.css` — значения из `tokens.json` без
  изменений (primitive → semantic → component; темы светлая, тёмная,
  контрастная через `data-mayak-theme`). `src/styles/tokens.css` добавляет
  только то, чего в `tokens.json` нет: роли текста в rem (следуют настройке
  размера интерфейса), высоты элементов (40 px мышью, 48 px на сенсорном
  экране), производные цвета через `color-mix` от семантических токенов,
  тени и движение. Прямых HEX-значений в компонентах нет.
- **Никаких стандартных элементов управления.** Нет `<select>`,
  `<input type="range">`, `<input type="color">`, видимых системных флажков и
  радиокнопок, подсказок `title`: у каждого есть собственный компонент
  (`PopUpButton`, `Slider`, `ColorWell`, `Checkbox`, `RadioGroup`, `Switch`,
  `SegmentedControl`, `MenuButton`, `Tooltip`, `Sheet`, `Toast`, `TokenField`…).
  Системный флажок остаётся в DOM невидимым — ради клавиатуры и экранного
  диктора, рисуется собственный квадрат.
- **Компоненты раздела 6 дизайн-системы:** `ScreenTitle`, `SectionLabel`,
  `NoteCard`, `Hero` (иллюстрация `islands-art`, 2.2:1 в узком месте и 3:1
  в широком — по ширине самого блока), `BottomNav`, `SyncStatus`, `FileCard`, `Card`.
- **Иллюстрация.** `src/assets/islands-art-960.webp` и `-1600.webp` — сжатые
  копии `islands-art.png` из пакета дизайн-системы. В тёмной теме кадр
  затемняется, в контрастной — скрыт.

## Раскладка приложения

| Ширина | Раскладка |
| --- | --- |
| от 900 px | верхняя панель (название, статус синхронизации, настройки), навигация 208–232 px, список 288–336 px, заметка |
| 701–899 px | список и заметка, разделы — в выдвижной панели |
| до 700 px (телефон) | один экран, заголовок 32 px, поиск, изображение-герой с числом записей, карточки, нижняя навигация из четырёх разделов; верхней панели нет |

Главное действие заметки — «Диктовать» (заливка основным действием).

## Проверки

Живой каталог всех компонентов во всех состояниях: `apps/web/catalog.html`
(`npm run dev -w @mayak/web`, затем `/catalog.html`). Автотест
`apps/web/e2e/catalog.spec.ts` проверяет:

- axe (WCAG 2.2 AA) в светлой, тёмной и контрастной теме;
- работу с клавиатуры;
- радиусы и цвета по токенам, отсутствие размытия фона;
- отсутствие стандартных элементов управления;
- отсутствие горизонтальной прокрутки на ширине телефона.

`apps/web/e2e/app.spec.ts` и `mobile.spec.ts` проверяют экраны приложения:
axe в темах, ширины 320–1440 px, зоны касания 48 px на телефоне.
Контраст вторичного текста на всех поверхностях всех тем не ниже 4.5:1 —
`apps/web/test/appearance.test.ts`.
