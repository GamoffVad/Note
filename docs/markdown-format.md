# Markdown-представление заметки

Каноническое хранение — JSON-документ из блоков (`packages/domain/src/document.ts`). Markdown используется для экспорта и импорта (`toMarkdown`, `fromMarkdown`).

## Экспорт

```markdown
# Заголовок

Текстовый блок как есть,
включая переносы строк.

- [ ] Невыполненная задача
- [x] Выполненная задача

[Материалы проекта.pdf](mayak-file:6f1c…-uuid)
```

- Заголовок — первая строка `# …`, если он не пуст.
- Блоки разделяются пустой строкой; подряд идущие задачи — по строке на задачу.
- Перенос строки в тексте задачи или подписи вложения заменяется пробелом.
- Вложение — ссылка на `mayak-file:<fileId>`; в `]` и `\` подписи экранируются.

## Импорт и обратимость

- Импорт всегда создаёт **новые** UUID блоков (ТЗ, раздел 3). Полную структуру с id, тегами и закреплением сохраняет JSON-архив.
- Гарантия, проверенная тестом: `toMarkdown(fromMarkdown(toMarkdown(doc))) === toMarkdown(doc)`.
- Потери при круге «документ → Markdown → документ»:
  - теги, `pinned` и `conflictOf` не переносятся;
  - текстовый блок с пустыми строками внутри становится несколькими блоками;
  - строка текстового блока вида `- [ ] …` при импорте становится задачей;
  - если заголовок пуст, а первый блок начинается с `# `, при импорте он станет заголовком.
