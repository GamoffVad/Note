    Как установить

    Windows
    Запустите файл. Если появится «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
    macOS
    Откройте файл и перетащите «Маяк» в «Программы». При первом запуске: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
    Android
    Откройте скачанный файл и разрешите установку из этого источника.
    Linux
    AppImage: сделайте файл исполняемым и запустите. Ubuntu и Debian: sudo apt install ./файл.deb.

    Войдите по почте в «Настройки → Аккаунт и синхронизация» — у каждого своё хранилище заметок.
